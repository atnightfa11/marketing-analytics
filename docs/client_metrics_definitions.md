# Client Metrics Definitions

- **Pageviews**: count of tracked pageview events.
- **Unique Visitors**: daily presence estimate.
- **Sessions**: session start events after inactivity window.
- **Conversions**: conversion events (auto/manual).
- **Revenue**: imported or event-derived revenue metric.

## Privacy/data handling summary

- No cookies required.
- No persistent user identifiers in SDK payload.
- Origin checks enforced at token bootstrap and ingest.
- Upload tokens are short-lived.
- Site keys are hashed at rest.
- Free/Standard launch keeps Pro ingest disabled.
